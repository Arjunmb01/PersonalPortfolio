# Arjun M B — Full-Stack Developer Portfolio

An interactive, cinematic portfolio engineered with modern web technologies, smooth kinetic motion, and luxury editorial aesthetics.

## ✨ Features

- **Kinetic Hero Experience:** Smooth scroll-driven character translation and interactive mouse parallax choreographing the subject with GSAP ScrollTrigger and Canvas rendering.
- **Responsive Architecture:** Clean layout designed for desktop, tablet, and mobile with verified clearance from fixed navigation headers.
- **Smooth Inertia Scrolling:** Integrated with Lenis for butter-smooth momentum scrolling and scroll-bound animations.
- **Interactive Capability Deck:** Dynamic engineering focus cards showcasing full-stack capabilities, cloud containerization, and distributed API expertise.
- **Production Showcase:** Real-world featured projects including MedixFlow, SSK Handlooms, InfinityTech, and Chatify with live preview links and architectural highlights.
- **Interactive Project Filtering & Lightbox:** Filter work by Full Stack, Frontend, Backend, and Mobile categories with rich modal deep-dives.
- **Modern Tech Stack:** React 19, TypeScript, Vite, Tailwind CSS, GSAP, and Framer Motion.

## 🛠️ Tech Stack

- **Core:** React 19, TypeScript, Vite 8
- **Styling:** Tailwind CSS, Custom Design System
- **Animation & Motion:** GSAP 3 (ScrollTrigger), Framer Motion, Lenis Smooth Scroll
- **Icons:** Lucide React
- **Graphics:** HTML5 2D Canvas & WebGL / Three.js

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Arjunmb01/PersonalPortfolio.git

# Navigate to project directory
cd PersonalPortfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
